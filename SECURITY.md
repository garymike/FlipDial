# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Do not open a public issue.

Include what you found, how to reproduce it, and the impact you expect. You will get an acknowledgement, and fixes are released as soon as practical.

## Scope

Anything in this repository, including the ingest worker, server, web app, container images and default configuration. See [docs/threat-model.md](docs/threat-model.md) for what the project defends against.

## Supported versions

Until v1, only the latest commit on `main` receives fixes.
