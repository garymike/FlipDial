# Demo data

Everything in this folder is invented. Names, companies, emails (all on `.example` domains), phone numbers (all in the 555 fictional range) and card designs are made up.

This is the only folder where vCards and card images may be committed. Add demo data here when a test or the live demo needs it.

## What's here

- `contacts.json`: invented contacts and cards waiting for review
- `cards/`: generated card art (SVG), front and back

Both are generated by `scripts/make-demo.py`. Edit that script and run it again rather than editing the files by hand.

## The live demo

`npm run build:demo` (in `web/`) builds the real web app with an in-browser stand-in for the server that serves this data. The **Demo** workflow publishes it to GitHub Pages on every push to `main` that touches `web/` or `demo/`. Importing, exporting and backups are turned off there.
